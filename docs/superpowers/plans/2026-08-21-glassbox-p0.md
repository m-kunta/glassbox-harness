# Glassbox P0 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build and validate the P0 tracing foundation, integrate one replenishment agent, and stop with an evidence-backed SDK ergonomics report.

**Architecture:** A dependency-neutral `events` layer feeds a bounded, fail-open collector that writes SQLite and content-addressed blobs. The public SDK owns trace, span, decision, and evidence contexts without importing persistence implementation. All disabled and failure paths preserve wrapped-agent behavior.

**Tech Stack:** Python 3.11+, Pydantic 2, SQLite, pytest, pytest-asyncio, import-linter, Ruff, mypy, Hatchling.

## Global Constraints

- Implement P0 only; do not create P1/P2 runtime modules.
- Bind all timestamps to UTC RFC 3339 and all IDs to ULIDs.
- `GLASSBOX_ENABLED=0` performs zero writes and preserves return values and exceptions.
- Telemetry is bounded and fail-open; public instrumentation never raises into agent code.
- Redaction runs before hashing or persistence.
- Use SQLite foreign keys, WAL mode, and a configurable busy timeout.
- Preserve the approved API and data invariants in `docs/superpowers/specs/2026-08-21-glassbox-design.md` and `docs/spec/glassbox-spec-v1.2.md`.
